1需求描述：筛选模块 — 生命周期筛选

功能描述

在筛选栏新增「生命周期」筛选项，允许运营人员按商品所处生命周期阶段过滤列表数据。

交互逻辑

  • 控件类型：下拉选择框，支持多选
  • 选项值：导入期 / 成长期 / 成熟期 / 衰退期 / 清仓期
  • 默认值：空（即不限制，展示全部商品）
  • 多选逻辑：选中多个阶段时，展示满足任一阶段的商品（OR 逻辑）
  • 与其他筛选项遵循页面已有的「且 / 或」逻辑联动

验收标准

  • 筛选栏出现「生命周期」下拉，默认显示「不限制」
  • 支持同时选中多个生命周期值
  • 选择后列表数据按所选生命周期过滤
  • 清空/重置筛选后，生命周期恢复为空（不限制）

异常处理

若接口返回生命周期字段为空，该商品在筛选时按「无生命周期」处理，不纳入任何阶段的筛选结果。

3需求描述：操作列 — 编辑弹窗（合并入口）

功能描述

将原「编辑商品目标」与「修改商品生命周期」合并为统一的「编辑」入口。点击操作列「编辑」按钮，弹窗内同时展示商品目标设置和生命周期修改两个模块。

触发与弹窗顶部

  • 触发：操作列点击「编辑」按钮，弹窗打开
  • 弹窗顶部展示所选商品的 ASIN + 店铺/站点，用于确认操作对象
  • 「当前配置（回显）」区域展示该商品当前已保存的所有配置值

「商品目标设置」模块字段

字段必填单位回显
目标ACOS必填%回显当前值
ACOS上限选填%回显当前值
CVR及格线选填%回显当前值
预算上限选填¥回显当前值

「生命周期」模块

  • 控件：下拉选择框，选项：导入期 / 成长期 / 成熟期 / 衰退期 / 清仓期
  • 默认显示「请选择」，不自动回填当前值
  • 若用户未选择，保存时生命周期不变

保存逻辑

  1. 点击「确认保存」→ 先对目标ACOS做非空校验
  2. 校验不通过：输入框下方展示「目标ACOS为必填项」提示，不提交
  3. 校验通过：调用接口保存，成功后关闭弹窗并刷新当前行数据
  4. 点击「取消」或点击蒙层：关闭弹窗，不提交任何改动

验收标准

  • 点击「编辑」后弹窗出现，顶部正确展示当前商品 ASIN 及店铺/站点
  • 回显区域正确展示该商品当前所有配置值
  • 商品目标各输入框正确回填当前值
  • 生命周期下拉默认为「请选择」，不回填
  • 目标ACOS为空时提交，出现必填校验提示
  • 保存成功后弹窗关闭，列表当前行数据同步更新
  • 取消/点击蒙层不触发保存

异常处理

  • 接口保存失败：Toast 提示「保存失败，请重试」，弹窗保持打开
  • 目标ACOS输入非数字：前端过滤，只允许输入数字及小数点
4需求描述：批量操作工具栏

功能描述

勾选一条或多条商品后，顶部展示批量操作工具栏，支持5种批量操作。所有配置项均需用户重新填写，不回显当前值。

触发方式

  • 勾选任意行 → 批量工具栏自动展示在列表上方，显示已选条数
  • 取消全部勾选 → 工具栏自动隐藏

批量操作清单（5种）

操作名称弹窗内容必填
批量编辑目标ACOS目标ACOS 输入框（%）必填
修改商品生命周期生命周期 下拉选择必填
批量编辑ACOS上限ACOS上限 输入框（%）必填
批量编辑CVR及格线CVR及格线 输入框（%）必填
批量编辑预算上限预算上限 输入框（¥）必填

弹窗交互规范

  • 每个弹窗顶部展示「已选 N 条商品，所有配置项均需重新填写」提示
  • 弹窗内只展示对应字段的输入控件，不展示其他字段
  • 点击「确认批量保存」后，将填写值批量写入所有已选商品
  • 批量操作不影响未被选中的商品

验收标准

  • 勾选商品后批量工具栏出现，正确显示已选条数
  • 5个批量操作按钮均可点击并弹出对应弹窗
  • 弹窗内「已选 N 条」数量与实际勾选数一致
  • 批量保存成功后列表刷新，已选商品对应字段数据更新
  • 批量操作弹窗内字段不回显历史值
  • 取消全部勾选后工具栏自动隐藏

异常处理

  • 批量接口部分失败：Toast 提示「X 条保存成功，Y 条失败，请检查后重试」
  • 全部失败：Toast 提示「批量保存失败，请重试」
